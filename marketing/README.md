# Marketing / présentation

- **presentation.html** — présentation + démo interactive de la solution (HTML
  autonome, ouvrable dans un navigateur, thème clair/sombre). Vues démo en direct :
  pricer obligataire, optimisation MASI, stress testing, conformité AMMC.
- **kanyon-architecture.pptx** — schéma de l'application (titre, architecture,
  9 modules, flux de valeur).
- **build_architecture_pptx.js** — générateur du PPTX (`node build_architecture_pptx.js`,
  nécessite `npm install pptxgenjs`).
