# Présentation

- **presentation.html** — présentation « QCG Markets » avec démo interactive
  (HTML autonome, ouvrable dans un navigateur, thème clair/sombre). Intro brève
  puis vues démo en direct : pricer obligataire, optimisation MASI, stress
  testing, conformité AMMC. Sans tarifs.
- **QCG_Markets-schema.pptx** — schéma de l'application (titre, architecture,
  9 modules, flux de valeur).
- **build_architecture_pptx.js** — générateur du PPTX (`node build_architecture_pptx.js`,
  nécessite `npm install pptxgenjs`).
